# tCppFall26Module01
tCppFall26Module01

Create Five C++ Projects

Create the following five separate C++ projects.

Each project should compile and run successfully.

Commit the source code for each completed project to your Module 01 GitHub Classroom repository.

Project 1 — Hello World

Project name:

helloWorld

Primary source file:

helloWorld.cpp

Create a basic C++ program that displays:

Hello, World!

Your program should use the coding style we use in class, including:

using namespace std;

Compile and run your program.

Then commit and push the project to GitHub.

Project 2 — Double an Integer

Project name:

doubleInteger

Primary source file:

doubleInteger.cpp

Write a program that:

Asks the user to enter an integer.

Stores the integer in a variable.

Multiplies the integer by 2.

Displays the result.

Example:

Enter an integer: 12

Twice 12 is 24

Use meaningful camelBack variable names.

Compile and test the program using several different values.

Then:

Commit → Push → Verify

Project 3 — Triple an Integer

Project name:

tripleInteger

Primary source file:

tripleInteger.cpp

Write a program that:

Asks the user to enter an integer.

Stores the value.

Multiplies the integer by 3.

Displays the result.

Example:

Enter an integer: 7

Three times 7 is 21

Compile and test your program.

Then:

Commit → Push → Verify

Project 4 — Add Two Integers

Project name:

sumTwoIntegers

Primary source file:

sumTwoIntegers.cpp

Write a program that:

Asks the user for the first integer.

Asks the user for the second integer.

Adds the two integers.

Displays the sum.

Example:

Enter the first integer: 15

Enter the second integer: 20

The sum is 35

Use meaningful camelBack variable names such as:

firstNumber

secondNumber

sum

Compile and test the program with several different combinations of numbers.

Then:

Commit → Push → Verify

Project 5 — Friendly Greeting

Project name:

friendlyGreeting

Primary source file:

friendlyGreeting.cpp

This program gives you a small preview of C++ strings.

Follow my professor video to learn the small amount of string code you need for this exercise.

Write a program that:

Asks the user for their name.

Stores the name in a variable named something like userName.

Displays a friendly greeting using their name.

Example:

What is your name? Dennis

Hello, Dennis! Welcome to C++ programming!

Compile and test your program using several different names.

Then:

Commit → Push → Verify

Do not worry if you do not completely understand strings yet. We will study them in more detail later.
